My3dtiles 0.3.0

2024/4/2

视频介绍

▤大文件已外迁网盘：演示视频 20240402-000000-My3dtiles0.3版本介绍.mp4 体积超过 3MB，未随文档入库，请到百度网盘「My3dtiles资料附件」条目取回。

简要说明

  • 多种类型文件(m3t.json/tileset.json/geojson/czml等)通过多种方式自动识别并加载
  • 增加多种样例数据，有场景的、3dtiles的、czml等等，方便用户调试
  • 针对3dtiles，可以拾取获得属性信息、纹理信息等，方便调试3dtiles数据
  • 新增大屏UI，多种UI对象，方便用户开发大屏应用
  • 继续优化用户交互体验，重新整理工具栏和命令窗口
  • 谷歌影像服务出现问题，目前使用天地图影像作为默认影像

更新说明

新增可配置的UI面板

可以直接在场景中配置UI面板，这些UI面板全部可自定义配置。方便用户直接在项目中使用。

以上面板支持全屏展示。

以上UI面板，可以在命令面板中找到。

加载谷歌全球瓦片数据

加载方法是打开命令面板，在样例数据中选择谷歌3ddtiles。

拾取查看3dtiles的详细信息

可以通过拾取的方式查看3dtiles数据的统计信息、纹理信息、属性信息。 统计信息包含占用的显存大小、绘制的顶点数量、三角面片数等。 纹理信息包含用户使用的纹理尺寸、纹理压缩格式等。 属性信息则可以显示当前拾取中的feature的所有属性信息。

其他更新

场景文件后缀更改为m3t.json
支持多种类型文件直接拖拽打开

支持多种类型文件直接拖拽打开，支持的文件类型有m3t.json、tileset.json、geojson、topojson、czml、kml、kmz、gltf、glb。

新增鼠标拾取操作选择工具栏

三个按钮的功能分别是：

  1. 拾取后编辑位置
  2. 拾取后弹出信息面板
  3. 拾取(鼠标左键点击)后不做任何操作
继续完善命令面板

Ctrl + ~键快速唤醒命令面板。

命令面板中新增示例数据

新增的示例包含一个场景文件，若干个3dtiles数据，若干个glb模型，若干个geojson、czml、kml文件。

数字城市场景，可以直接加载一个已经场景案例。

新增视角工具栏

五个按钮的工作分别是：

  1. 场景树上新增一个视角，以后可以双击场景树上的该节点，自动飞入到当前视角。
  2. 飞入到北京视角
  3. 飞入到中国视角
  4. 飞入到全球视角
  5. 场景打开时，是否使用使用上一次打开场景时的视角作为初始视角
三维交互操作改进

之前滚动滚轮操作可以进行视角缩放，但是滚轮滚动一格，很可能缩放的间距过大。所以新增了shift+鼠标右键。按住shift键和鼠标右键以后，通过移动鼠标，可以进行细微地放缩视角。

3dtiles数据的编辑操作

可以对3dtiles数据进行位置编辑和姿态编辑。 位置编辑时，左侧属性面板会显示位置信息(分别是经度纬度高度)，右侧三维窗口中会显示坐标架。左侧编辑框，和右侧的坐标架上都可以进行操作，数据实时同步。

姿态编辑时，需要首先打开左侧面板的姿态编辑选项，此时右侧的三维窗口中就会出现三个圈。用户可以同时在左侧编辑框和右侧三维窗口中进行操作。需要注意的是，姿态编辑的前提是需要三维瓦片的位置已设定，如果位置未设定，那么旋转圈出不来。

默认使用天地图影像服务

因为谷歌影像服务目前不可用，内置的影像服务为天地图影像。用户亦可自行更换其他影像服务。

部分类型未来将弃用

考虑到维护成本较高，部分场景对象类型将被弃用，其中包括My3dtiles、MyGltf、MyCzml、MyGeoJson、MyKml、MyImageModel。请尽量不要使用这些类型。

后续计划

  1. 有用户提议能否打包，能发布网页版。未来将提供相关功能。

  1. 可能会考虑提供多个gltf打包成3dtiles的功能。
  2. 可能会考虑提供3dtiles直接修改位置(直接修改源文件)的功能。

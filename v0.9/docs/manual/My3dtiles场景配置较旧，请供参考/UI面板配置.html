概览

My3dtiles同时是一个低成本数字孪生解决方案。您可以配置好UI和功能，实时连接物联网数据，以三维可视化的方式动态实时直观地展示各类数据。适用于大屏展示、领导规划决策、实时模拟演练。

只要执行全屏的菜单命令，就可以直接当大屏来使用。

面板的位置可以任意设置。

上面的圆环图本身有两个部分组成。它的子节点是一个ECharts面板。这个ECharts面板可以随意更换。ECharts面板本身的类型是EChartsDiv，可以任意配置ECharts的图表。下面会有介绍。

我们提供了一些基础UI面板，这些面板功能强大，可以任意定制。方便用户设计成自己需要的模式。

EChartsDiv

先创建ECharts前置脚本这个对象，此时左下角会有提示信息，提示几个js文件加载成功。

万一没加载成功，可以用下面的方法，强制执行一下。

然后再加载EChartsDiv就好啦

加载后的效果如下图所示。这是一个默认的ECharts图表，不太好看。然后我们就可以自己配置了。

在这里就可以填写自己需要的配置信息。这个配置信息咱们可以到ECharts官网示例中去找。

打开ECharts官网的示例页面。 书签 书签

拷贝上图左侧的代码。

option = {
  title: {
    text: 'Referer of a Website',
    subtext: 'Fake Data',
    left: 'center'
  },
  tooltip: {
    trigger: 'item'
  },
  legend: {
    orient: 'vertical',
    left: 'left'
  },
  series: [
    {
      name: 'Access From',
      type: 'pie',
      radius: '50%',
      data: [
        { value: 1048, name: 'Search Engine' },
        { value: 735, name: 'Direct' },
        { value: 580, name: 'Email' },
        { value: 484, name: 'Union Ads' },
        { value: 300, name: 'Video Ads' }
      ],
      emphasis: {
        itemStyle: {
          shadowBlur: 10,
          shadowOffsetX: 0,
          shadowColor: 'rgba(0, 0, 0, 0.5)'
        }
      }
    }
  ]
};

把上述代码复制到编辑器中，再点击确定。

大屏展示

可以围绕3dtiles数据配置一个小型场景，内部包含电子标牌、兴趣点、屏幕标题、OD线、视角等。配置完的场景还具备全屏模式，自动开启环绕飞行模式，从而作为大屏展示使用。

不锁数据，不锁工具，不锁人

数字孪生项目最怕的不是做不出来，是做完了离不开供应商。m3t 的前提恰好相反：能开放的部分全部开放。

内核本身是一个网页，外面套了层桌面壳。所以它能离线跑，也能只把内核发到服务器上给人看。

它不是「又一个大屏软件」，是把 Cesium 的开发门槛从 JS 降到 JSON，再降到鼠标。

数据独立
全部使用开放格式：3dtiles、glTF、geojson、kml、czml。脱离厂家，原始数据依然能用。
工具独立
免费、无授权、无 USB 加密狗、不联网登录。下载到机器就能用，离线机器一样跑。
开发独立
没有把 Cesium 封起来。可以继续写原生 Cesium 代码，也可以自研插件并自行决定是否收费。
信创可用
纯 JS 应用，不绑 CPU 架构与显卡驱动。装上 Chrome 或 Firefox 就能运行。
已知短板
三维真实感渲染偏弱。要照片级质感可融合 WebGPU，或改用 EarthSDK / UE。新版已支持 Cesium 与 WebGPU 融合渲染。

能读什么，能摆什么

本地与在线数据都能加载；在线数据复制地址粘贴即可。

# m3t.u32.cn 发布流程（简要）

> 2026-11-20 起。仓库：m3t-site 本地仓库（GitHub 公开仓 `u32-cn/m3t-site`）
> 本文件是运维文档，不随站点对外（`privacy-scan.py` 的 SKIP_TOP 已排除 docs/）。

## 链路

```
m3t-site 本地改 HTML → git commit → publish.mjs --push（推 GitHub）
    → GitHub Pages 自动构建（仓库根 = 站点根，main 分支）
    → EdgeOne 回源加速（规则 rule-3o7f4du6mmpl：站点回源 u32-cn.github.io，
      /download/* 代理回源 github.com release）
    → https://m3t.u32.cn/
```

无构建步骤、无 OSS。没有别的仓库参与，一切内容直接在 m3t-site 里改。

## 日常改内容（3 步）

```bash
cd <m3t-site 本地仓库>
# 1. 直接改 HTML/静态文件，然后 commit
git add -A && git commit -m "..."
# 2. 校验 + 发布
node scripts/publish.mjs && node scripts/publish.mjs --push
# 3. 等 Pages 构建（--status 查看），内容有实质更新再刷缓存
node scripts/publish.mjs --purge
```

## 软件发新版（以 1.0 为例）

1. 安装包资产上传 GitHub release：`gh release create 1.0.0 <文件...> --repo u32-cn/m3t-site`
   - ⚠ GitHub 会把资产名里的括号改写成点号（`(web)` → `.web.`），下载链接必须用改写后的名字
2. 站点加下载页：`v0.9/docs/download/` 下新建/改 HTML
   - 主链接：`https://m3t.u32.cn/download/<tag>/<文件名>`（EdgeOne 代理 GitHub，国内加速）
   - 备用链接：`https://gitee.com/vtxf3d/my3dtiles/releases/download/<tag>/<文件名>`（Gitee 原链，直连 CDN）
3. 新版本目录 `v1.0/` 与旧 `v0.9/` 并行，根 `index.html` stub 改跳 `/v1.0/`
4. 走上面「日常改内容」3 步发布

## 发布前红线

- 公开仓：隐私扫描必须过（`publish.mjs` 自带；本机路径示例、公开署名已白名单）
- `--push` / `--purge` 须经用户同意后执行
- 仓库根 `.nojekyll` 不能删；仓库体积上限 1G（现约 304M）

## 回滚

GitHub Pages 历史部署可回退；EdgeOne 规则存档在 ai-pages 仓库的 `.vtxf/edgeone的站点加速配置/` 目录（旧 OSS 源站版备份在同目录，带 `-20261119-OSS源站旧版` 后缀）。
